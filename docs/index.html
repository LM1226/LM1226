实验亮点

📊

多浓度设计

设置 0、50、100、200、400、800 mg/L 六个浓度梯度，清晰比较不同处理对插条生根的差异。

🌿

指标完整

从生根率、平均生根数和平均根长三个方面，对生根状况进行全面比较与分析。

🧠

理论迁移

帮助学生理解生长素类似物的“双重性”，并把实验现象与理论知识有效联系起来。

实验流程

操作步骤

  • 选取生长健壮无病虫害的空心菜插条。
  • 配制不同浓度的 NAA 溶液并处理插条基部。
  • 将插条插入沙床或基质中，保持适宜环境。
  • 观察并记录生根情况，统计相关指标。
  • 依据实验数据分析最适浓度与抑制阈值。

实验结论：低浓度 NAA 能够促进空心菜插条生根，且在一定范围内，促进作用随着浓度增大而增强；但是超过最适浓度后，生根率和根数明显下降，表现出生长素类似物的两重性。
